## 本轮实际修复与限制

新增单目录字面量 ls 的 FD 绑定，支持如 `ls -la src 2>/dev/null | head -50`、`cd . && ls -la src`，比较真实 Bash 输出并测试绑定后目录被换成项目外 symlink。多目标、递归、`-d` 与未证明选项仍回退。`cd . && ls src 2>/dev/null | head` 在当前 tree-sitter AST 中将含 cd 的 list 放在 pipeline 下，目录状态传播仍未证明，明确保持 unknown。

默认上下文补充通用范围与拒绝规则：普通浏览不顺手读运行时配置；区分总数、截断结果及推断；拒绝后不换工具绕过。这是模型行为指引，真正拒绝由执行门保证，实测并未保证自由浏览总能遵守提示。
