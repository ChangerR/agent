# 终端交互约定

## 阅读与运行状态

- 主区域保留对话与操作记录；当前阶段、权限模式、输入和待发送消息位于底栏。
- 完成的思考默认一行，成功工具默认两行，失败工具最多四行。折叠输出按实际可见行限高，长中文或长路径不会撑满窄屏。
- `Ctrl+O` 展开全部思考、工具参数与输出；`/details 编号` 只查看一条完整记录。折叠不改变模型历史或保存内容。
- 空闲时 Enter 发送，运行时 Enter 排队。下一条待发送内容保留在输入区标题；`/queue clear` 清空队列。运行中 Esc 中断并清空队列。
- 窄窗口优先显示权限模式与思考级别，模型名允许截断。

## 设置与审批共用底部面板

- `❯` 表示当前候选，`当前` 表示已经生效的设置。筛选模型不更改当前模型；Enter 应用，Esc 返回且不更改。
- 模型与推理设置在下一次模型请求生效，可能发生于当前用户轮次内；模型选择不会切换 provider 或 endpoint。
- 权限模式对后续权限检查生效，不追溯修改已经等待用户处理的审批。说明文字依据审批模型、危险操作强制询问配置显示。
- 审批先展示操作，再展示允许一次、记住规则、拒绝。每个新请求初始都未选择，必须用方向键或鼠标选中后再按 Enter；鼠标点击本身不授权。
- 记住规则按实际工具匹配目标解释：通常是路径、命令或模式；没有匹配目标的插件会授权整个工具。匹配目标相同并不代表其他参数相同。规则随会话保存与恢复。
- Tab 查看完整详情，包含选中授权选项的范围说明、理由和完整参数；Enter 从详情返回选项，不直接授权；审批与保存确认返回选项后清除候选，必须重新选择。支持方向键、PgUp/PgDn、Home/End 滚动。
- 审批优先于设置，结束后恢复原筛选与未发送草稿。Enter 确认后的固定 500ms 内重复 Enter 会被吸收，避免落入恢复的草稿或设置候选。
- Esc 拒绝当前审批；运行中审批的 Ctrl+C 仍中断当前轮。普通设置面板的 Ctrl+C 只关闭面板。

## 带边框的设置与权限卡片

- `/settings` 是设置入口；`/permissions` 打开权限控制中心，原有日志移动到 `/permissions audit`。输入区提示和命令补全均可发现设置。
- 模型、思考、权限设置使用完整边框，审批使用不同颜色的「Agent 正在请求权限」卡片。工具与操作摘要始终位于操作选项上方；正常窗口还显示触发审批的真实来源和理由。
- 审批详情携带同一工具调用 ID、目录、管线/规则/危险检测/自动审批员来源、匹配规则及完整参数，不按工具名字猜测并发调用来源。预览截断不丢弃完整详情；终端控制序列不会执行。
- 24×8 窗口优先保留边框、工具、当前可选操作及取消/详情提示，↑↓ 可以遍历所有选项。模型筛选、详情和草稿在审批结束后恢复。
- Enter 确认审批后的短暂保护不延长；Esc 拒绝与外部取消不会吞掉恢复草稿的 Enter。新审批始终需要重新选择；鼠标只选择，不执行授权。

### 会话行为与项目默认值

- 会话权限模式改变前单独确认，只影响后续权限检查；当前等待中的审批仍需决定。记住的会话规则可查看并逐条确认删除，随会话保存和恢复。
- 项目默认编辑器支持权限模式、allow/ask/deny 规则和审批模型。编辑、取消字段和浏览菜单均不写配置；必须单独选择保存并确认。
- 保存只更新项目配置中的明确编辑字段，保留无关和插件字段。已加载引擎不自动更新，新的默认值在下次启动生效；恢复已有会话仍可能恢复其自己的模式与规则。
- 全局继承规则只读。规则优先级仍是 deny → 危险检测 → allow → ask → 模式，不能用项目 allow 越过全局 deny。危险操作强制询问开关不在此编辑器内修改。
- 写入失败或检测到外部修改时，不替换现有文件、不修改当前运行权限，保留草稿供处理。
